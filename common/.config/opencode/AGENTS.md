## Code Changes

- Prefer simple, readable configuration over defensive complexity.
- Preserve existing behavior unless explicitly asked to change it.
- Do not modify files outside the requested scope.
- Explain potentially destructive operations before executing them.
- Inspect and reuse existing implementations before introducing new ones.
- Avoid unrelated refactoring and unnecessary dependencies.
- Verify changes with relevant tests and report what could not be verified.

## Tool Usage
- Filter large tool outputs before adding them to context.
